# LensPro 仓库管理系统（Electron 客户端）使用文档

## 1. 文档目的
本文档面向一线仓库管理员与系统维护人员，介绍 LensPro Electron 客户端的安装、登录、日常操作、常见问题与排错方法。

---

## 2. 系统说明
LensPro 采用“Electron 桌面端 + Spring Boot 后端”架构：
- 桌面端用于登录、库存管理、出库管理、密码维护。
- 后端服务提供数据接口与文件上传。

启动后客户端会先检查版本；若服务端判定当前客户端版本已废弃，程序会提示更新并退出。

---

## 3. 运行环境与准备

### 3.1 运行环境
- Windows / macOS / Linux（支持 Electron 的环境）
- 可访问后端接口地址（HTTP/HTTPS）

### 3.2 客户端配置
客户端通过 `app/config.ini` 中的 `url` 指向后端服务地址：

```ini
url=http://<服务器IP或域名>:<端口>
```

示例（仓库当前配置）：
```ini
url=http://192.168.0.3:8081
```

> 注意：如果地址不可达，登录时会提示“无法连接服务器”。

---

## 4. 启动与退出

### 4.1 启动方式（开发环境）
1. 进入 `app/` 目录。
2. 安装依赖：`npm install`
3. 启动客户端：`npm start`

### 4.2 版本校验
启动后会请求：
- `GET /api/config/get_version`

若服务端返回的 `build` 大于当前客户端内置 `BUILD`，程序会提示版本已废弃并自动退出。

### 4.3 托盘行为
- 关闭窗口默认不会直接退出，会最小化到托盘。
- 托盘右键菜单：
  - 打开窗口
  - 退出
- 双击托盘图标可重新打开窗口。

---

## 5. 登录

1. 启动后先显示登录窗口。
2. 输入访问密码并点击“登录”或按回车。
3. 客户端会调用：
   - `GET /api/config/check_password?password=...`
4. 登录成功后进入主界面；失败会显示错误信息（如“访问密码错误”）。

## 7. 详细功能操作

## 7.1 概览
用于查看统计信息与近期动态：
- 器材总数
- 在库中数量
- 已出库数量
- 标签数量
- 近期操作日志

适用于每日开工快速确认库存状态。

## 7.2 库存浏览
可浏览全部库存并进行筛选、分页与快捷操作：
- 标签筛选
- 全选/多选
- 添加到出库队列
- 刷新列表

列表主要字段包括：项目ID、项目名、缩略图、标配清单、标签、备注、状态。

常用接口（示例）：
- `GET /api/warehouse/get_list`
- `GET /api/config/get_filter`

## 7.3 新增项目
录入新器材项目信息：
- 项目名称（必填）
- 物品照片（可选，单张）
- 配件清单（必填，`|` 分隔）
- 标签（可选）
- 备注（可选）

提交后调用：
- `POST /api/warehouse/add`

## 7.4 修改项目
通过项目 ID 查询后可编辑项目数据，并可执行状态变更：
- 入库 / 出库状态更新
- 文本字段更新
- 缩略图更新
- 删除（若界面启用）

常用接口（示例）：
- `GET /api/warehouse/get_item?id=...`
- `POST /api/warehouse/update`
- `POST /api/warehouse/update_status`
- `POST /api/warehouse/delete`

## 7.5 出库（新建出库单）
流程建议如下：
1. 通过项目 ID 逐条添加到出库队列。
2. 需要时上传附件（合同、交接资料等）。
3. 填写姓名、电话、截止日期、备注。
4. 点击“提交出库”。

提交接口：
- `POST /api/outbound_report/addA`

相关能力：
- 刷新附件队列
- 清空出库队列
- 校验项目是否在库

## 7.6 出库列表
用于查看与跟踪已提交订单：
- 订单 ID
- 用户
- 出库总量
- 剩余天数
- 状态
- 操作（完结订单、查看出库报告）

常用接口（示例）：
- `GET /api/outbound_report/get_report_list`
- `POST /api/outbound_report/finish_order`

## 7.7 修改密码
用于更新系统访问密码。

调用接口：
- `POST /api/config/alter_password`

## 7.8 关于
用于查看系统说明与版本信息。若含外链，客户端仅允许打开 `http` / `https` 链接。

## 8. 日常操作建议（仓库场景）
- **班前**：先看“概览”确认在库/出库总体情况。
- **发货/借用前**：在“库存浏览”确认状态后再加入出库队列。
- **提交出库时**：务必填写截止日期与联系方式，必要时上传附件。
- **班后**：在“出库列表”核对即将到期订单，必要时完结订单。

## 9. 常见问题与排错

### 9.1 登录时报“未配置服务器地址”
原因：`config.ini` 未设置 `url`。
处理：配置正确后重启客户端。

### 9.2 登录时报“无法连接服务器”
排查顺序：
1. 检查服务器地址与端口是否正确。
2. 检查客户端机器网络连通性。
3. 检查后端服务是否已启动。

### 9.3 启动后提示版本废弃并退出
原因：服务端要求更高版本客户端。
处理：更新客户端安装包后重试。

### 9.4 点关闭后程序仍在运行
说明：这是托盘驻留机制，属正常行为。
处理：在托盘菜单点击“退出”。

## 10. 运维补充（管理员）
- 客户端令牌在运行时由内存管理，不建议在前端明文存储。
- 建议将 `app/config.ini` 纳入环境化管理（按测试/生产分离）。
- 生产环境建议启用 HTTPS，并收紧服务端 CORS 与密码策略。
